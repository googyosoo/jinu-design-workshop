# 지누의 디자인 공작소 (Jinwoo Design Workshop)

디자인 시스템 프롬프팅 엔지니어링과 실시간 UI 렌더링을 통합한 프론트엔드 워크스페이스입니다. 16대 글로벌 표준 디자인 스타일을 브라우저에서 즉시 체험하고, 프롬프트와 5대 실무 UI 컴포넌트 소스코드를 복사하여 활용할 수 있습니다.

---

## 1. 프로젝트 주요 기능

### 1) 16대 디자인 시스템 갤러리
- 글로벌 인터페이스 디자인 흐름을 대표하는 16개 핵심 스타일을 카드 형태로 전시합니다.
- 각 스타일마다 고유 컬러 팔레트, 디자인 철학, 프롬프트 원문, 실시간 SVG 목업을 제공합니다.
- 프롬프트 복사, v0 및 Lovable 연동용 Tailwind 프롬프트 복사, Claude 및 ChatGPT 마스터 프롬프트 복사, Cursor 시스템 룰 복사를 지원합니다.

### 2) 실시간 라이브 샌드박스
- 16개 디자인 스타일을 상단 샌드박스에서 즉시 전환하여 렌더링 상태를 확인합니다.
- A/B 스플릿 뷰를 통해 서로 다른 두 스타일의 시각 계층과 조형미를 나란히 비교합니다.
- 데스크톱(1440px), 태블릿(768px), 모바일(390px) 뷰포트 전환으로 반응형 레이아웃을 검증합니다.

### 3) 5대 핵심 UI 컴포넌트 킷
- 각 스타일에 최적화된 5대 컴포넌트(버튼, 입력 폼, 카드, 배지, 네비게이션)를 모달 창에서 제공합니다.
- 스타일별 지오메트리 규격(곡률, 테두리, 그림자, 타이포그래피)을 시각 사양표로 요약합니다.
- 표준 HTML+CSS 및 최신 Tailwind CSS v4 형태 중 원하는 포맷을 선택해 원클릭으로 소스코드를 복사합니다.

### 4) 디자인 토큰 스튜디오 및 에이전틱 린터
- 주 색상, 모서리 곡률(0~32px), 그림자 깊이, 표면 밝기, 자간을 실시간 조작합니다.
- 조작한 디자인 토큰을 Tailwind CSS v4 `@theme`, 표준 CSS `:root`, W3C 및 Figma 표준 JSON으로 내보냅니다.
- 실시간 자가 비평 린터(Self-Critique Linter)가 조형 규칙 위반(스위스 기능주의 곡률 위반, 브루탈리즘 블러 위반 등)을 감지하고 원클릭 자동 치유를 수행합니다.

### 5) 3인 합의형 AI 스타일 스튜디오
- 디자인 아키텍트, 디자인 엔지니어, 디자인 비평가 3인의 관점을 융합한 메타 프롬프트를 생성합니다.
- 추출한 JSON 토큰 스펙을 등록하여 17번째 이후 커스텀 스타일을 동적으로 갤러리와 샌드박스에 추가합니다.

## 2. 16대 디자인 시스템 목록

1. **애플 감성 프리미엄 미니멀 (Apple Minimal)**: 고요한 여백, 절제된 타이포그래피, 마이크로 인터랙션
2. **스위스 인터내셔널 기능주의 (Swiss Functional)**: 12열 그리드 질서, 헬베티카 서체, 절대 직각(0px)
3. **극도의 투명성 베어리 데어 UI (Barely-there UI)**: 경계선을 걷어내고 콘텐츠 자체를 인터페이스화
4. **단계적 정보 공개 시스템 (Progressive Disclosure)**: 인지 과부하를 방지하는 2단계 인터페이스 노출
5. **머티리얼 3 익스프레시브 (Material 3 Expressive)**: 둥근 토널 컨테이너, 다이내믹 스프링 모션
6. **인간 중심의 따뜻한 감성 UI (Warm UI)**: 베이지와 테라코타 컬러, 부드러운 호흡의 카드
7. **벤토 그리드 모듈러 시스템 (Bento Grid)**: 크기로 위계를 드러내는 고밀도 반응형 구획
8. **바우하우스 기능주의 기하학 UI (Bauhaus Functional)**: 삼원색과 기초 도형을 통한 기능 중심 조형
9. **모던 네오 브루탈리즘 (Modern Neo-Brutalism)**: 굵은 외곽선, 0px 블러 하드 섀도우, 과감한 대비
10. **오가닉 앤 안티 그리드 (Organic Anti-Grid)**: 비대칭 물결 곡선, 흙빛 색채, 여유로운 시각 휴식
11. **촉각적 아날로그 앤 스큐어모피즘 (Tactile Analog)**: 음각 버튼, VU 미터, 실물 장비 질감
12. **레트로 퓨처리즘 신스웨이브 (Retrofuturism)**: 1980년대 네온 글로우, CRT 모니터 스캔라인 감성
13. **현대적 에디토리얼 디자인 (Contemporary Editorial)**: 세리프 서체, 단정된 매거진 레이아웃
14. **키네틱 타이포그래피 (Kinetic Typography)**: 활자 자체가 주인공이 되는 역동적 가변 타이포
15. **인터랙티브 스크롤리텔링 (Scrollytelling)**: 스크롤 진행에 맞춘 3단계 내러티브 전달
16. **라이트 게이미피케이션 (Light Gamification)**: 연속 달성 스트릭, 경험치 프로그레스, 시각적 보상

## 3. 로컬 실행 방법

외부 빌드 도구 설치 없이 최신 웹 브라우저에서 바로 실행할 수 있습니다.

### 방법 1. 브라우저로 직접 열기
프로젝트 루트 경로에 위치한 `index.html` 파일을 더블 클릭하거나 크롬 브라우저로 드래그하여 실행합니다.

### 방법 2. 로컬 웹 서버 실행 (권장)
```bash
# Python 3 내장 서버 활용
python -m http.server 8080

# 브라우저 접속
http://localhost:8080
```

또는 Node.js 환경에서 정적 서버를 실행할 수 있습니다:
```bash
npx serve .
```

## 4. 소스코드 빌드 및 E2E 테스트 검증

프로젝트 소스코드는 `src/` 디렉터리에 모듈화되어 있으며, 빌드 스크립트를 실행해 단일 배포용 `index.html`을 생성합니다.

### 소스코드 빌드
```bash
node build_gallery.js
```

### 전수 E2E 자동화 검증
Chrome과 Puppeteer 환경에서 5대 핵심 테스트 스위트를 검증합니다:

```bash
# 1. 16개 전 스타일 전환 및 80개 컴포넌트 킷 렌더링, 코드 복사 검증
node verify_16styles_kit_copy.js

# 2. 스웜 고도화 기능(반응형 뷰포트, 린터, AI 스튜디오) 검증
node verify_swarm_features.js

# 3. 디자인 토큰 스튜디오 조작 및 W3C JSON 내보내기 검증
node verify_token_studio.js

# 4. 컴포넌트 킷 모달 및 17번째 커스텀 스타일 등록 검증
node verify_grill_features.js

# 5. 프롬프트 복사 및 스타터 템플릿 다운로드 회귀 검증
node verify_full_suite.js

# 6. 보안 크레덴셜 및 개인정보 유출 검사 (0건 검증)
node scan_secrets.js
```

## 5. 프로젝트 디렉터리 구조

```text
├── index.html                   # 통합 배포용 단일 웹 애플리케이션
├── build_gallery.js             # 갤러리 마크업 및 모듈 인라인 주입 빌더
├── prompts_data.json            # 16개 디자인 시스템 정규화 데이터
├── src/
│   ├── presets.js               # 16개 스타일 CSS 프리셋 및 라이브 렌더러
│   ├── kit.js                   # 5대 컴포넌트 지오메트리 맵 및 모달 뷰어
│   └── agentic.js               # 린터, 스웜 브리프 복사, 합의형 메타프롬프트
├── assets/
│   ├── desktop_showcase.png     # 데스크톱 검증 스크린샷 (1440px)
│   ├── mobile_showcase.png      # 모바일 검증 스크린샷 (390px)
│   └── ...                      # 기능별 E2E 검증 스크린샷
├── verify_16styles_kit_copy.js  # 16개 스타일 및 코드 복사 E2E 자동 검증
├── verify_swarm_features.js     # 반응형 뷰포트 및 린터 검증
├── scan_secrets.js              # 크레덴셜 및 개인정보 보안 감사 스크립트
└── README.md                    # 프로젝트 안내 문서
```
